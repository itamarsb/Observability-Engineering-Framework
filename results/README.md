# Results

No experimental results have been published yet. Pilot runs are used only to calibrate parameters and are not reported as results.

## Data organisation

| Location | Content | Versioned |
|---|---|---|
| `runs/pilot/`, `runs/campaign/` | One folder per run (`<scenario>-<repetition>-<UTC timestamp>`): run manifest, raw k6 output, probe data, server-side events, exports from Prometheus, Loki and Tempo, container logs and `checksums.sha256` | No — kept outside Git in three copies |
| [`processed/`](processed/) | Consolidated summaries (`summary-*.csv`) generated from the analysed runs | Summaries only |
| [`charts/`](charts/) | Figures generated by the plotting scripts | No — regenerated from the data |
| [`evidence-index.csv`](evidence-index.csv) | Traceability index: each piece of evidence, its source file, the script or query that produced it, and where it is used | Yes |

Runs that are aborted or invalid are preserved and marked as such; they are listed but excluded from consolidation.

## Processing pipeline

```bash
python3 scripts/analyze_run.py runs/campaign/<run_id>          # indicators per phase and per run
python3 scripts/consolidate.py runs/campaign results/processed  # consolidated summaries
python3 scripts/plot_load.py results/processed/summary-runs.csv # load-response figure (C0–C3)
python3 scripts/plot_run.py runs/campaign/<run_id>              # time series of a perturbation run (C4–C7)
```

The integrity of a run folder can be checked with `sha256sum -c checksums.sha256` inside the folder.
